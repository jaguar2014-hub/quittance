Quittances-App — Architecture du système

Génération et envoi automatique de quittances de loyer · cloud Render · OAuth Google

Le frontal — ce que vous voyez

  • • Une page web unique (quittances-app.html)
  • • 3 onglets : Locataires, Nouvelle quittance, Historique
  • • Le PDF est généré côté client (jspdf, navigateur)
  • • Authentification Google (vous devez être dans la whitelist)

Le serveur — ce qui travaille

  • • Express.js reçoit les requêtes HTTPS
  • • Vérifie le cookie de session (sauf /api/health)
  • • Génère le PDF côté serveur aussi (jspdf)
  • • Envoie via SMTP Gmail avec PJ attachée
  • • Sauvegarde locataires + historique sur disque

Le cloud — où ça tourne

  • • Render héberge Node.js (gratuit, plan free)
  • • GitHub stocke le code + déclenche le redéploiement
  • • Google Cloud gère l'authentification OAuth
  • • Gmail envoie le mail final au locataire
  • • Le service s'éteint après 15 min d'inactivité
